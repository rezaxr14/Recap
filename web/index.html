What this page does not prove

  • The environment is a deterministic mock API, not production traffic.
  • The deterministic headline uses a 256-d hashing embedder. The selectable live dataset uses nomic 768-d and one small local model on one machine.
  • Elasticsearch is single-node. There is no scale claim here.
  • Gold v3 memories are labelled synthetic fixtures; decoys are synthetic too.
  • Task success counts only externally verified completion. A safe abstention is reported separately, not relabelled as success.
  • A live model can select the correct memory and still fail to execute its strategy. Harmful transfer records the failed outcome; it does not prove the wrong memory was selected.
